<p class="wp-block-paragraph"></p>



<p class="wp-block-paragraph">We are excited to announce the public release of the Data Commons <a href="https://modelcontextprotocol.io/docs/getting-started/intro">Model Context Protocol (MCP)</a> Server. The MCP Server provides a standardized way for AI agents to consume Data Commons data natively. Developers can easily write and deploy AI agents and applications that deliver trustable, sourced Data Commons information back to the end user. Analysts and data scientists can use simple, natural language to get fast answers, without needing to learn or directly interact with complex underlying APIs. Here are a few examples of the full range of high-level data queries:</p>



<ul class="wp-block-list">
<li>Exploratory: &#8220;What health data do you have for Africa?&#8221;</li>



<li>Analytical: &#8220;Compare the life expectancy, economic inequality, and GDP growth for BRICS nations.&#8221;</li>



<li>Generative: &#8220;Generate a concise report on income vs diabetes in US counties.&#8221;</li>
</ul>



<p class="wp-block-paragraph">To learn more about the immediate benefits and use cases of the Data Commons MCP Server, see the <a href="https://developers.googleblog.com/en/datacommonsmcp">Google for Developers blog</a>.</p>



<h4 class="wp-block-heading">Ready to try?</h4>



<p class="wp-block-paragraph">The server is freely available as a <a href="https://pypi.org/project/datacommons-mcp/">PyPi package</a>. It returns data from datacommons.org by default or can be configured to run against a Custom Data Commons instance.&nbsp;</p>



<p class="wp-block-paragraph">You can use it with your favorite MCP client or get started right away with <a href="https://github.com/datacommonsorg/agent-toolkit/blob/main/docs/quickstart.md">Gemini CLI</a>.</p>



<p class="wp-block-paragraph">In addition, as part of this launch, we have provided a <a href="https://google.github.io/adk-docs/">Google ADK</a> sample agent in our <a href="https://github.com/datacommonsorg/agent-toolkit/tree/main/packages/datacommons-mcp/examples/sample_agents">Github repository</a> as well as <a href="https://colab.research.google.com/github/datacommonsorg/agent-toolkit/blob/main/notebooks/datacommons_mcp_tools_with_custom_agent.ipynb">a Colab notebook</a> that shows you how to develop your own Python agent step by step.</p>



<p class="wp-block-paragraph">For complete documentation, see our <a href="https://github.com/datacommonsorg/agent-toolkit/blob/main/docs/user_guide.md">User Guide</a>.</p>
