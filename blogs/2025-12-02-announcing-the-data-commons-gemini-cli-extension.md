<p class="wp-block-paragraph">Earlier this year, we announced the public release of the Data Commons <a href="https://developers.googleblog.com/en/datacommonsmcp/">Model Context Protocol (MCP) Server</a>. The MCP Server provides a standardized way for AI agents to consume Data Commons data natively. Analysts can ask high-level questions in natural language, while developers can easily create AI agents customized for their needs.&nbsp;</p>



<p class="wp-block-paragraph">The server provides tools that are optimized to answer queries such as:</p>



<p class="wp-block-paragraph">Exploratory: &#8220;What poverty indicators for India do you have?&#8221;</p>



<p class="wp-block-paragraph">Analytical: &#8220;List out the GDP per capita for all the OECD countries, rank-ordered by GDP.&#8221;</p>



<p class="wp-block-paragraph">Generative: &#8220;Write a summary of the birth rates in China and India since 1970.&#8221;</p>



<p class="wp-block-paragraph">When used with Gemini CLI as the client, Data Commons also allows grounding of responses from the GoogleSearch tool with authoritative data.&nbsp;</p>



<p class="wp-block-paragraph">Today, we are making it even easier to use Data Commons with <a href="https://geminicli.com/">Gemini CLI</a> by releasing a <a href="https://geminicli.com/extensions/">Gemini CLI extension</a>. The extension provides an out-of-the-box agent, with a context file that guides the model on how to query the MCP server tools. The extension simplifies installation and setup so you can get started in minutes.&nbsp;</p>



<p class="wp-block-paragraph">Check out <a href="https://github.com/gemini-cli-extensions/datacommons">https://github.com/gemini-cli-extensions/datacommons</a> for instructions on installation and usage.</p>
