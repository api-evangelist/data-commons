<p class="wp-block-paragraph"></p>



<p class="wp-block-paragraph">For any meaningful data analysis, context is everything. A consistent theme in the feedback from our user community has been the need for greater clarity around a chart&#8217;s source, scope, and methodology. We agree that without this crucial context, building trust and deriving deep insights can be a significant challenge.</p>



<p class="wp-block-paragraph">To address this directly, we are announcing a comprehensive update to our charts across our platform, designed to empower more confident analysis by providing an improved level of transparency and control.</p>



<p class="wp-block-paragraph"></p>



<h3 class="wp-block-heading">Transparency about the data</h3>



<p class="wp-block-paragraph">The first step toward greater clarity is our new comprehensive &#8220;About this data&#8221; dialog. Now available on every chart, it provides an at-a-glance summary of the crucial information behind the data points. You will be able to see on each chart an “<strong>About this data</strong>” link, that will bring a dialog with the following information:</p>



<ul class="wp-block-list">
<li><strong>Source:</strong> The specific organization or publication the data originates from</li>



<li><strong>Topic:</strong> The broader category the data belongs to</li>



<li><strong>Data range:</strong> The time period covered by the dataset.</li>



<li><strong>Observation period:</strong> The frequency of the data points (e.g., yearly, quarterly).</li>



<li><strong>Measuring method:</strong> The specific methodology and notes&nbsp; used to put together the data</li>
</ul>



<p class="wp-block-paragraph">This brings an improved level of transparency, allowing you to instantly assess the context and credibility of the data you are viewing.</p>

<p class="wp-block-paragraph"></p>



<h4 class="wp-block-heading">More control: See and select from multiple datasets and facets</h4>



<p class="wp-block-paragraph">Deeper analysis often requires seeing data from different perspectives. A common challenge in data exploration is the inability to easily see or select alternative facets for the same variable.</p>



<p class="wp-block-paragraph">Our latest update aims at giving you direct control. While our platform will still select a facet for the initial page results, you now have the ability to see if there are other facets available for that variable and select them directly for further analysis. This empowers you to validate findings and explore nuances between sources right within the chart module.</p>



<figure class="wp-block-image size-full"><img alt="Animated graphic showing a data chart for the population in the labor force in the United States, alongside options to download data, view API calls, and explore other datasets." class="wp-image-834" height="480" src="https://i0.wp.com/blog.datacommons.org/wp-content/uploads/2025/10/Facets.gif?resize=764%2C480&#038;ssl=1" width="764" /></figure>



<p class="wp-block-paragraph"></p>



<h4 class="wp-block-heading">An integrated workflow: Download data and access API Calls</h4>



<p class="wp-block-paragraph">Understanding the data is the first step; using it effectively is the next. To bridge this gap, we&#8217;ve equipped every chart module with download tools to streamline your workflow and integrate our data into your own projects. For analysts and developers, we are now displaying the API code needed to programmatically fetch the data shown in the chart.</p>



<p class="wp-block-paragraph">These enhancements are built on a core belief: powerful data tools should provide transparency, control, and efficiency. Explore a chart on our site today to see the new features in action. We are excited to see what you uncover and welcome your continued feedback as we improve our platform.</p>
